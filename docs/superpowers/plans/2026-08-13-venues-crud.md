# /v1/venues CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/v1/venues` CRUD resource to Eventify on a new Express 5 + Zod 4 layered backend (routes → controller → service, `HttpError` + centralized error middleware, `validate`/`validateQuery` input middleware, in-memory `Map` store), migrating the existing raw-`http` `/health` and `/events` endpoints onto the same Express app unchanged.

**Architecture:** `src/app.ts` builds an Express app (no `listen()`); `src/server.ts` imports it and starts listening. Cross-cutting pieces (`HttpError`, `errorHandler`, `validate`/`validateQuery`) live in `src/errors/` and `src/middleware/`. The venues resource is split into `src/schemas/venue.schema.ts` (Zod), `src/services/venues.service.ts` (Map store + business rules), `src/controllers/venues.controller.ts` (req/res glue), `src/routes/venues.routes.ts` (wiring). `/health` and `/events` get their own thin route files with their existing logic verbatim.

**Tech Stack:** Node.js (native TypeScript execution via `node --watch`), Express 5, Zod 4, TypeScript 7 (strict, `erasableSyntaxOnly`).

**Reference spec:** `docs/superpowers/specs/2026-08-13-venues-crud-design.md`

## Global Constraints

- Strict TypeScript everywhere — no `any` (from `CLAUDE.md`).
- ESM only — relative imports must include explicit `.ts` extensions (from `CLAUDE.md`), e.g. `import { HttpError } from "../errors/HttpError.ts";`.
- No enums — use literal union types instead (from `CLAUDE.md`).
- `tsconfig.json` has `"erasableSyntaxOnly": true` — **no constructor parameter properties** (e.g. `constructor(public x: number)`), no runtime namespaces/enums. Declare and assign class fields explicitly in the constructor body instead.
- `tsconfig.json` has `"noUncheckedIndexedAccess": true` — index-signature property access (e.g. `req.params.id`, since Express's default `ParamsDictionary` is `{ [key: string]: string }`) types as possibly `undefined`; cast with `as string` where the route guarantees the param exists.
- Zod 4 API: use top-level format schemas like `z.email()`, not the deprecated `z.string().email()`.
- No test framework exists in this repo (only `tsc --noEmit`) and the spec deliberately doesn't add one. Every task below substitutes `npm run typecheck` plus a manual `curl` check (once code is wired into `app.ts`) for the usual write-test/run-test steps.
- IDs are generated with `node:crypto`'s `randomUUID()`; timestamps are `new Date().toISOString()`.

**Interfaces:**
- Produces: `HttpError` class with `status: number`, `message: string` (inherited from `Error`), `details?: unknown`, and static helpers `HttpError.badRequest(message, details?)`, `HttpError.notFound(message)`, `HttpError.conflict(message)`, each returning an `HttpError`.

- [ ] **Step 1: Write the file**

```ts
export class HttpError extends Error {
  status: number;
  details?: unknown;

  constructor(status: number, message: string, details?: unknown) {
    super(message);
    this.name = "HttpError";
    this.status = status;
    this.details = details;
  }

  static badRequest(message: string, details?: unknown): HttpError {
    return new HttpError(400, message, details);
  }

  static notFound(message: string): HttpError {
    return new HttpError(404, message);
  }

  static conflict(message: string): HttpError {
    return new HttpError(409, message);
  }
}
```

```ts
import type { ErrorRequestHandler } from "express";
import { HttpError } from "../errors/HttpError.ts";

export const errorHandler: ErrorRequestHandler = (err, _req, res, _next) => {
  if (err instanceof HttpError) {
    res.status(err.status).json({
      error: {
        message: err.message,
        ...(err.details !== undefined ? { details: err.details } : {}),
      },
    });
    return;
  }

  console.error(err);
  res.status(500).json({ error: { message: "Internal server error" } });
};
```

### Task 4: validate / validateQuery middleware

**Files:**
- Create: `src/middleware/validate.ts`

**Interfaces:**
- Consumes: `HttpError` from `src/errors/HttpError.ts` (Task 2).
- Produces: `validate(schema: ZodType)` — Express middleware factory that parses `req.body`, replacing it with the parsed value on success or calling `next(HttpError.badRequest(...))` on failure. `validateQuery(schema: ZodType)` — same for `req.query`, storing the parsed value on `req.validatedQuery` (since Express 5's `req.query` has no setter). Declares `req.validatedQuery?: unknown` via Express namespace augmentation — later tasks read it with an `as` cast to the specific schema's inferred type.

- [ ] **Step 1: Write the file**

```ts
import type { NextFunction, Request, Response } from "express";
import type { ZodType } from "zod";
import { HttpError } from "../errors/HttpError.ts";

declare global {
  namespace Express {
    interface Request {
      validatedQuery?: unknown;
    }
  }
}

export function validate(schema: ZodType) {
  return (req: Request, _res: Response, next: NextFunction): void => {
    const result = schema.safeParse(req.body);
    if (!result.success) {
      next(HttpError.badRequest("Invalid request body", result.error.flatten()));
      return;
    }
    req.body = result.data;
    next();
  };
}

export function validateQuery(schema: ZodType) {
  return (req: Request, _res: Response, next: NextFunction): void => {
    const result = schema.safeParse(req.query);
    if (!result.success) {
      next(HttpError.badRequest("Invalid query parameters", result.error.flatten()));
      return;
    }
    req.validatedQuery = result.data;
    next();
  };
}
```

- [ ] **Step 1: Write the file**

import { z } from "zod";

export const createVenueSchema = z.object({
  name: z.string().trim().min(1),
  address: z.string().trim().min(1),
  capacity: z.number().int().positive(),
  contactEmail: z.email(),
});

export const updateVenueSchema = createVenueSchema
  .partial()
  .refine((data) => Object.keys(data).length > 0, {
    message: "At least one field required",
  });

export const listVenuesQuerySchema = z.object({
  limit: z.coerce.number().int().positive().max(100).optional().default(20),
});

export type CreateVenueBody = z.infer<typeof createVenueSchema>;
export type UpdateVenueBody = z.infer<typeof updateVenueSchema>;
export type ListVenuesQuery = z.infer<typeof listVenuesQuerySchema>;

### Task 8: Venues service (in-memory Map store)

**Files:**
- Create: `src/services/venues.service.ts`

**Interfaces:**
- Consumes: `HttpError` (Task 2); `Venue` from `src/domain.ts` (Task 6); `CreateVenueBody`, `UpdateVenueBody` from `src/schemas/venue.schema.ts` (Task 7).
- Produces: `createVenue(input: CreateVenueBody): Venue`, `listVenues(limit: number): Venue[]`, `getVenueById(id: string): Venue`, `updateVenue(id: string, patch: UpdateVenueBody): Venue`, `deleteVenue(id: string): void` — consumed by the controller (Task 9).

- [ ] **Step 1: Write the file**

```ts
import { randomUUID } from "node:crypto";
import { HttpError } from "../errors/HttpError.ts";
import type { Venue } from "../domain.ts";
import type { CreateVenueBody, UpdateVenueBody } from "../schemas/venue.schema.ts";

const venues = new Map<string, Venue>();

function assertNameAvailable(name: string, excludeId?: string): void {
  for (const venue of venues.values()) {
    if (venue.name === name && venue.id !== excludeId) {
      throw HttpError.conflict("Venue name already exists");
    }
  }
}

export function createVenue(input: CreateVenueBody): Venue {
  assertNameAvailable(input.name);

  const venue: Venue = {
    id: randomUUID(),
    name: input.name,
    address: input.address,
    capacity: input.capacity,
    contactEmail: input.contactEmail,
    createdAt: new Date().toISOString(),
  };

  venues.set(venue.id, venue);
  return venue;
}

export function listVenues(limit: number): Venue[] {
  return Array.from(venues.values()).slice(0, limit);
}

export function getVenueById(id: string): Venue {
  const venue = venues.get(id);
  if (!venue) {
    throw HttpError.notFound("Venue not found");
  }
  return venue;
}

export function updateVenue(id: string, patch: UpdateVenueBody): Venue {
  const existing = getVenueById(id);

  if (patch.name !== undefined && patch.name !== existing.name) {
    assertNameAvailable(patch.name, id);
  }

  const updated: Venue = { ...existing, ...patch };
  venues.set(id, updated);
  return updated;
}

export function deleteVenue(id: string): void {
  getVenueById(id);
  venues.delete(id);
}
```

```ts
import type { Request, Response } from "express";
import * as venuesService from "../services/venues.service.ts";
import type { CreateVenueBody, UpdateVenueBody, ListVenuesQuery } from "../schemas/venue.schema.ts";

export function create(req: Request, res: Response): void {
  const venue = venuesService.createVenue(req.body as CreateVenueBody);
  res.status(201).json(venue);
}

export function list(req: Request, res: Response): void {
  const { limit } = req.validatedQuery as ListVenuesQuery;
  res.status(200).json(venuesService.listVenues(limit));
}

export function getById(req: Request, res: Response): void {
  const venue = venuesService.getVenueById(req.params.id as string);
  res.status(200).json(venue);
}

export function update(req: Request, res: Response): void {
  const venue = venuesService.updateVenue(req.params.id as string, req.body as UpdateVenueBody);
  res.status(200).json(venue);
}

export function remove(req: Request, res: Response): void {
  venuesService.deleteVenue(req.params.id as string);
  res.status(204).send();
}
```
